Buttons for actions. `Button variant="neon"` is the primary glowing CTA; `variant="ghost"` is the neutral bordered button. `IconButton` is the 34px square for single glyphs.

```jsx
<Button variant="neon" icon="⬇">Exportar a MTG Arena</Button>
<Button variant="ghost">Cancelar</Button>
<IconButton>≡</IconButton>
```

Use neon sparingly — one primary action per view. Ghost for secondary/toolbar actions.
